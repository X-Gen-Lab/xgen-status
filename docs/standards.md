# 工程规范采用声明

采用 X-Gen 工程规范 1.0.0，来源为 xgen-roadmap 本地提交 `3c60419b4ab067a6d6f4ef25832d72694d9aa624` 的 `docs/standards/README.md`。规范正文由 roadmap 唯一维护，本文不复制规则。发布前需提供可获取的固定来源；独立源码构建不依赖兄弟仓库存在。

## 范围与补充

- 生产 C、公开头、C++ 测试、CMake 与文档适用相关条款。
- 根 `.clang-format` 和 `.editorconfig` 为 Nexus 受控副本，无格式覆盖；源码注释使用英文及反斜杠 Doxygen。
- `xgs::status` 是无对象实现的 INTERFACE target。状态码数值稳定；枚举底层表示由目标 ABI 决定，不声明固定序列化布局。
- 字符串函数无堆、无可变全局状态；返回只读静态文本，不需要生命周期初始化和并发锁。
- 版本 `.h.in` 由 CMake 处理，不能作为有效 C 格式化。生成头接受独立 C/C++ 包含和安装消费检查。
- 生产 C11 与主机 C++17 分离。GoogleTest 1.16.0、共享质量包和外部工具需要显式准备，生产配置不联网。

## 检查边界

行为、头文件、源码/安装消费和错误请求通过真实构建与运行验证；语义契约及来源仍需评审。统一质量入口为 `tools/quality.py`，它调用显式安装的 xgen-quality。工具版本与默认策略在共享包维护，`tools/quality.json` 声明本模块采用版本和源码范围。

生产覆盖率分母仅为启用 strings 时的 `src/status.c`。仅类型的配置没有可插桩函数，不伪造百分比。完整镜像、ISR 时间和硬件高水位不由本库主机结果证明。

无代码诊断豁免。源代码许可证确认、共享质量最终验证、远端执行与发布状态分别记录于 [实施记录](implementation-log.md)，不能根据工具配置存在推断已经通过。
